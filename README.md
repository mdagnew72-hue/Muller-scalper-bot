# MULLER FOREX ROBOT ANALYZER - NATIVE ANDROID PROJECT
Built with Kotlin and Jetpack Compose for Samsung Galaxy S24 Ultra & Android devices.

## How to Build in Android Studio:
1. Open Android Studio (Ladybug, Koala, Jellyfish, or newer).
2. Click "Open..." and select this unzipped folder.
3. Wait for Gradle Sync to complete.
4. Connect your Samsung Galaxy S24 Ultra via USB (make sure USB Debugging is ON).
5. Click the green 'Run' (Play) button or select 'Build' > 'Build APK(s)'.
